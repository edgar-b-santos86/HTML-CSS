Aplicação de Media Query em uma única CSS local

Nesta aula vimos que em projetos menores, é possível colocar todos os seletores de CSS com media queries de maneira local, ou em um único arquivo CSS externo, porém, assim como o professor Guanabara disse, eu també acho melhor colocar em arquivos separados pois fica tudo muito bagunçado.

Para que tudo funcione no mesmo arquivo CSS ou no CSS local, nós colocamos o seletor @media com o type screen e a feature orientation.

Quando fazemos isso, dentro deste seletor colocamos o seletor desejado que neste caso foi o body com as declarações necessárias para sua configuração, nossa CSS ficou assim:


                
@charset "UTF-8";

* {
    margin: 0px;
    padding: 0px;
    font-family: Arial, Helvetica, sans-serif;
}

html, body {
    width: 100vw;
    height: 100vh;
    background-color: #233eff;
    background-size: cover;
    background-repeat: no-repeat;
}

h1 {
    color: #fff;
    text-align: center;
    text-shadow: 2px 2px 3px #00000098;
    padding-top: 20px;
}

main {
    background-color: #ffffff52;
    color: #000000;
    text-align: justify;
    line-height: 1.5em;
    max-width: 900px;
    margin: auto;
    padding: 20px;
    border-radius: 10px;
}

@media screen and (orientation: portrait) {
    body {
        background-image: url(../imagens/cev-portrait.jpg);
        background-position: center bottom;
    }
}

@media screen and (orientation: landscape) {
    body {
        background-image: url(../imagens/cev-landscape.jpg);
        background-position: left bottom;
    }
}
