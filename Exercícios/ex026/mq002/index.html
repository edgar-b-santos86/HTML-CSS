Media Queries

Nesta aula iremos aprender a utilizar as Features das Media Queries.

As Media Queries possuem diversas features, e uma delas é a feature de orientação, que é utilizada para aplicar estilos diferentes dependendo da orientação do dispositivo, seja ele um smartphone, tablet ou até mesmo um monitor de computador.

Com a feature de orientação, é possível criar designs responsivos que se adaptam automaticamente à orientação do dispositivo, proporcionando uma melhor experiência de usuário.

Para utilizar a feature de orientação, basta especificar a condição "orientation" seguida do valor "portrait" para orientação retrato ou "landscape" para orientação paisagem no atributo "media" do link da folha de estilo.

Por exemplo, para aplicar estilos específicos para dispositivos em orientação retrato, você pode usar a seguinte sintaxe:

<link rel="stylesheet" href="estilos/retrato.css" media="screen and (orientation: portrait)">

E para aplicar estilos específicos para dispositivos em orientação paisagem, você pode usar a seguinte sintaxe:

<link rel="stylesheet" href="estilos/paisagem.css" media="screen and (orientation: landscape)">

Com essas media queries, você pode criar estilos personalizados para cada orientação, garantindo que seu site seja exibido de forma otimizada em qualquer dispositivo, independentemente da orientação da tela.

Sendo assim, nós criamos três estilos em CSS, sendo um com configurações gerais, um com configurações específicas para modo de exibição retrato e outro com modo de exibição paisagem.

Colocamos nos estilos com a feature orientation apenas a declarações que seriam diferentes para cada uma delas.

A diferença entre elas ficou assim:

orientation:portrait


            body {
                background-image: url(../imagens/cev-portrait.jpg);
                background-position: center bottom;
    
            }

orientation:landscape


            body {
                background-image: url(../imagens/cev-landscape.jpg);
                background-position: left bottom;
            }
