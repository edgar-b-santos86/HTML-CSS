Media Query

O que é uma Media Query?

Uma media query ou medias queries, é uma técnica em CSS que primite aplicar estilos diferentes para a mesma página, entretanto, de modo que cada um seja aberta em dispositivos diferentes, ou em diferentes tamanhos de tela, e até uma versão para impressão.

Com media query, é possível criar designs responsivos que se adaptam automaticamente ao tamanho da tela do dispositivo em que a página é exibida.

Neste nosso exemplo criamos esta página e nela teremos um estilo para telas e outro para impressão.

Neste caso criaremos estilos esternos para que possamos aplicá-los conforme o tipo de dispositivo.

A diferença é que no link da CSS, especificamos o tipo de mídia com o atributo "media", que define quando o estilo deve ser aplicado.

Nosso exemplo da media query está sendo utilizado aqui, ficou da seguinte forma.

Primeiro o link para a CSS de tela:

<link rel="stylesheet" href="estilos/tela.css" media="screen">

E abaixo o link para a CSS de impressão:

<link rel="stylesheet" href="estilos/impressora.css" media="print">

Agora o CSS apra tela:

            
    @charset "UTF-8";

    *{
        margin: 0;
        padding: 0;
    }

    body {
        background-color: rgb(179, 179, 179);
    }

    html {
        font-family: Arial, Helvetica, sans-serif;
        font-size: 1em;
    }

    header {
        background-image: linear-gradient(to bottom, rgb(179, 179, 179), rgb(66, 65, 65));
        color: white;
        text-align: center;
        padding: 30px;
        padding-bottom: 0px;
        box-shadow: 2px 2px 5px black;
    }

    header h1 {
        font-size: 2.5em;
        padding-bottom: 30px;
    }

    header ul {
        list-style: none;
    }

    header li {
        display: inline-block;
        margin: 10px;
        text-align: left;
    }   

    a {
        padding: 2px;   
        text-decoration: none;
        color: white;
    }

    a:hover {
        color: rgb(5, 5, 5);
        border-radius: 5px;
        background-color: white;
        transition-duration: 0.5s;
    }

    main {
        max-width: 650px;
        min-width: 350px;
        background-color: white;
        margin: auto;
        padding: 20px;
    }

    article {
        padding: 20px;
        line-height: 2em;
    }

    article h1 {
        margin: 20px;
    }

Agora vamos ver o estilo para impressão:

            
    @charset "UTF-8";
    * {
        margin: 0;
        padding: 0;
    }
    html {
    font-family: 'Courier New', Courier, monospace;
    font-size: 1.5em;
    line-height: 1.5em;
    }

    menu {
    display: none;
    }

Os valores existentes para o atributo media que se chamam media types, são elas:

  • screen: para telas de computador e dispositivos móveis
  • print: para impressão
  • all: para todos os tipos de dispositivos
  • speech: para leitores de tela
  • braille: para dispositivos de braille
  • projection: para projetores
  • handheld: para dispositivos móveis
  • embossed: para dispositivos de impressão em braille

Media Query é o conjunto de Media Types e Media Features.
