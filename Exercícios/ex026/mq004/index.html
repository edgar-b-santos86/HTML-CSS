Modile First

Nesta aula vimos que o conceito atual é primeiro criar um site que seja acessado por dispositivos móveis, que seja rápido e leve, entretanto, fazendo com que o usuário tenha uma voa experiência ao visitar nosso site no celular ou tablet por exemplo, e quando ele acessar em dispositivos com telas maiores, ele não sinta que a experiência do site foi "capada".

O conceito Mobile First traz algumas vantagens para o nosso trabalho como:

  • Facilidade na divulgação;
  • Melhoria na experiência do usuário;
  • Aumento de credibilidade;
  • Performance do sites.

Vamos aplicar o conceito do Mobile First a esta página e para as demais que vamos fazer a partir de agora.

Agora vamos criar dentro do arquivo mediaquery.css os estilos para os demais tamanhos de tela e vamos falar sobre Typical Device Breakpoints

Typical Device Breakpoints

Os pontos de quebra típicos para dispositivos ou Typical Device Breakpoints é o tamanho padrão de telas de acordo com os modelos mais comuns de dispositivos móveis com base no conceito mobile first, e essas medidas são passadas pelo consórcio W3C, e com o passar dos anos e avanço da tecnologia, esses valores têm sido ajustados para se adaptar às novas realidades dos dispositivos digitais.

Hoje em dia, os breakpoints típicos são:

  • 320px | 480px - para celulares;
  • 768px | 1024px - para tablets;
  • 1024px | 1200px - para desktops;
  • 1200px + - para desktops com telas maiores ou tvs.

Utilizando desses breakponts, nos criamos nossos estilos para que fiquem responsivos para cada dispositivo, a partir de um site criado com o conceito mobile first.

Nos conseguimos notar as diferanças no navegador no nosso pc pois conseguimos ajustar o tamanho da janela.

Nosso novo arquivo CSS, que está nomeado de mediaquery.css, ficou assim:

            
                @charset "UTF-8";

@media print{
    * {
        font-family: 'Courier New', Courier, monospace;
    }

    body {
        background-image: url(../imagens/back-print.jpg);
    }

    main {
        width: 90vw;
        border: 2px solid black;
    }

    main h1 {
        color: black;
        text-shadow: none;
    }

    img#phone {display: none;}
    img#tablet {display: none;}
    img#print {display: block;}
    img#pc {display: none;}
    img#tv {display: none;}

}

@media screen and (min-width: 768px) and (max-width: 1024px) {
    body {
        background-image: url(../imagens/back-tablet.jpg);
        img#phone {display: none;}
        img#tablet {display: block;}
        img#print {display: none;}
        img#pc {display: none;}
        img#tv {display: none;}
    }
}

@media screen and (min-width: 1025px) and (max-width: 1200px) {
    body {
        background-image: url(../imagens/back-pc.jpg);
        img#phone {display: none;}
        img#tablet {display: none;}
        img#print {display: none;}
        img#pc {display: block;}
        img#tv {display: none;}
    }
}

@media screen and (min-width: 1200px) {
    body {
        background-image: url(../imagens/back-tv.jpg);
        img#phone {display: none;}
        img#tablet {display: none;}
        img#print {display: none;}
        img#pc {display: none;}
        img#tv {display: block;}
    }
}

Ficou vísivel que criamos um media screen para cada tamanho de tela, chamando os breakpoints correspondentes, e para cada uma delas aplicamos uma imagem de fundo correspondente ao tamanho do dispositivo que irá utilizar o site.
