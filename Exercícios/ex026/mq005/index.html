Criando menus responsivos com Media Query

Nesta aula vamos aprender a criar menus responsivos com Media Query em CSS.

Faremos aqui aquele famoso menu hamburguer responsivo que geralmente aparece quando estamos utilizando dispositivos móveis.

Lembrando que primeiro criaremos o nosso css para o conceito mobile first, e para o desenvolvimento do menu entraremos um pouco no JavaScript.

A primeira coisa que fizemos foi criar o layout básico do nosso html que ficou da seguinte maneira:



    <body>
       <header>
            <h1>Menu Responsivo com Media Query</h1>
            <menu>
                <ul>
                    <li><a href="#">Opção 1</a></li>
                    <li><a href="#">Opção 2</a></li>
                    <li><a href="#">Opção 3</a></li>
                    <li><a href="#">Opção 4</a></li>
                    <li><a href="#">Opção 5</a></li>
                    <li><a href="#">Opção 6</a></li>
                </ul>
            </menu>
        </header>
        <main>
            <article>
                <h2>Criando menus responsivos com Media Query</h2>
                <p>Nesta aula vamos aprender a criar menus responsivos com Media Query em CSS.</p>
            </article>
        </main>
    </body>

Em seguida, criamos o estilo básico para a nossa página, no conceito mobile first:



    @charset "UTF-8";
    
    *{
        font-family: Arial, Helvetica, sans-serif;
        margin: 0;
        padding: 0;
    }
    
    body, html {
        background-color:white;
    }
    
    header {
        background-color: #756D6A;
    }
    
    header h1 {
        padding: 10px;
        text-align: center;
    }
    
    menu {
        display: none;
    }
    
    menu > ul {
        list-style-type: none;
    }
    
    menu > ul > li > a {
        display: block;
        padding: 10px;
        text-decoration: none;
        text-align: center;
        background-color: #4B3E37;
        color: white;
        border-top: 2px solid #A08375;
    }
    
    menu > ul > li > a:hover {
        background-color: #A08375;
    }
    
    
    main {
        width: 90vw;
        background-color: #A08375;
        margin: auto;
        margin-top: 10px;
        padding: 10px;
        border-radius: 10px;
    }
    article > h2 {
        padding-bottom: 20px;
    }
    
    article > p {
        text-align: justify;
        margin-bottom: 20px;
        text-indent: 20px;
    }

Assim definimos o estilo para telas de celular, e neste caso também já definimos a maio parte do estilo do nosso site até aqui.

Porém, como nosso objetivo é criar um menu responsivo do tipo "hamburguinho", precisamos primeiro incorporar o ícone atraves do HTML e do CSS, e para isso usaremos o site da Google.

Primeiro acess o Google e procure por Google Icons.

Atualmente o Google Icons faz parte do Google Fonts, pois os ícones são disponibilizados como uma fonte web.

Em seguida procure por Developer Guide. Nesta página tem todas as dicas para incorporar os ícones em seu projeto, entretanto, nós utilizamos a maneira mais simples.

Copiamos o link <link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined" rel="stylesheet" /> logo abaxo no title do nosso documento, isso faz com que possamos inmportar todas as fontes de estilo simbolo para nosso projeto.

Em seguida utilizamos a tag <i class="material-symbols-outlined">menu</i>, com isso estamos buscando a fonte de ícones do Google e dentro colocamos o nome do ícone desejado, o que neste caso é o nome menu.

Demos um id para essa tag, no caso o id é burger.

Agora, nós demos uma configuração para o nosso ícone de menu através de CSS, que ficou assim:

                

    i#burger {
        background-color: #4B3E37;   
        color: white;
        display: block;
        text-align: center;
        padding: 10px;
        cursor: pointer;
    }

    i#burger:hover {
        background-color: #A08375;
        color: black;
        transition-duration: 0.5s;
    }

Assim nosso menu hamburguinho está estilizado, entretanto, ainda não está funcionando como um menu responsivo, e para isso utilizamos JavaScript para controlar a exibição do menu.

Primeiro, damos um id para a tag menu, no caso o id é opcoes.

Em seguida, criamos a função clickMenu(), dentro da tag <i> que é onde puxamos a referência dentro do site da Google para o ícone hamburguinho, e a tag ficou assim:

                
                    
    <i id="burger" class="material-symbols-outlined" onclick="clickMenu()">menu</i>

Em seguida demos um id para a tag <ul> que contém as opções do menu, no caso o id é opcoes.

Agora criamos uma tag da função JavaScript mas de maneira local, logo abaixo do nosso <mais> que ficou assim:

                
                    
    <script>
        function clickMenu() {
            if (opcoes.style.display == 'block') {
                opcoes.style.display = 'none'
            }
            else {
                opcoes.style.display = 'block'
            }
        }
    </script>

Assim, quando clicamos no ícone de menu, a função clickMenu() é executada, e ela verifica se o menu está sendo exibido ou não, e alterna entre mostrar ou esconder o menu.

Informações Adicionais:

  • A tag <i></i> anteriormente era usada para que os textos em HTML ficassem em itálico, entretanto, no HTML5 ela foi redefinida para ser utilizada com ícones.
  • O Google Icons é um serviço gratuito do Google que oferece uma vasta coleção de ícones vetoriais para uso em projetos web e mobile. Ele é amplamente utilizado por desenvolvedores e designers para adicionar elementos visuais atraentes e funcionais aos seus sites e aplicativos.
