Explicação

Na primeira aula do curso em vídeo do professor Gustavo Guanabara, aprendemos a criar o código padrão para inicio de toda página HTML5 como segue abaixo.

    <!DOCTYPE html>
    <html lang="pt-Br">
    <head>
        <meta charset="UTF-8">
        <meta http-equiv="X-UA-Compatible" content="IE=edge">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Meu Primeiro Exercício</title>
    </head>
    <body>
    
    </body>
    </html>

O código acima é criado apenas digitando "!" e apertando o enter, isso usando o Visual Studio Code.

Dentro do HTML temos alguns elementos que são utilizados para que possamos fazer nosso código mais organizado e semântico.

Uma das primeiras coisas são as marcas que chamamos de tags, as tags são elementos que definem a estrutura e o significado de um documento HTML. Elas iniciam com "<" e terminam com ">" (colchetes angulares).

As duas áreas do documento HTML são: a área do cabeçalho (head) e a área do corpo (body).

Na área do cabeçalho (head) colocamos informações sobre o documento HTML, como o título da página, links para folhas de estilo CSS, scripts JavaScript, meta tags etc.

Na área do corpo (body) colocamos todo o conteúdo visível da página HTML.
