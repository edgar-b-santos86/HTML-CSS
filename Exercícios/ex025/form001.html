Meu Primeiro Formulário

Todo formulário deve estar entre as tags <form> e </form>, e assim vamos começar nosso primeiro formulário da maneira mais básica possível.

Lembrando, como o professor Guanabara gosta de dizer, nem sempre quando uma tag funciona quer dizer que é a maneira correta de se utilizar ou fazer um código.

Nome:

Sobrenome:

O código para o formulário acima ficou da seguinte forma:

<form>
        <p>Nome: <input type="text" name="nome" id="nome"></p>
        <p>Sobrenome: <input type="text" name="sobrenome" id="sobrenome"></p>
        <p><input type="submit" value="Enviar"></p>
    </form>

O parágrafo onde colocamos Nome e o campo para preenchimento do texto tem a tag <input> com os atributos type="text", name e id.

O atributo name é usado para identificar o campo quando o formulário é enviado ao servidor, enquanto o atributo id é usado para identificar o campo no documento HTML.

O tipo text indica que o campo é para entrada de texto. O botão de envio é criado com um input do tipo submit, que envia os dados do formulário para o servidor quando clicado.

O formulário acima ainda não está completo, pois primeiro temos que especificar para onde serão enviados os dados quando o formulário for submetido, e também não temos ligação ou associação definida entre o controle, que neste caso são os campos do formulário e o botão de envio, e o texto ao qual nomeamos o campo, essa ligação é muito importante para que além do formulario ter o ser devido funcionamento, os mecanismos de busca possam identificar os elementos corretamente, e também o navegador do usuário faça com que o campos funcionem corretamente.

Nos próximos vídeos, vamos aprender mais sobre isso e essa parte do curso é muito importante para quando iniciarmos o curso de JavaScript.

Aqui também podemos tirar preenchimento automatico de dados utilizando o atributo autocomplete com o valor "off", e o código ficaria assim:

        <form autocomplete="off">

Para onde são enviados os dados?

Os dados do formulário são enviados sempre para um servidor por meio de uma outra linguagem de programação com PHP, Java, Asp.NET, entre outras.

Para isso vamos colocar o atributo action na tag <form>.

No nosso exemplo, vamos colocar o valor do atributo action como "formulario.php", que é o nome do arquivo que irá processar os dados do formulário. O código do formulário ficaria assim:

        <form action="formulario.php">

A ação do envio do formulário sempre será executada quando o usuário clicar no botão de enviar.

Configurando o Formulário com o Label

Para criar a ligação/associação da palavra Nome com o campo onde será preenchido este dado, vamos usar a tag <label>.

Importante, para que os fomulários funcionem direito, é necessário que todo input tenha um atributo name e um atributo id associado.

O atributo name é muito útil para a linguagem PHP, e o atributo id é usado para linguagem JavaScript.

Aqui vamos refazer nosso código e criar a associação entre os labels e os campos de input:

Para nossa tag <label> utilizaremos no atributo for, mesmo o valor que colamos no atributo id, e o código ficaria assim:

        <label for="inome">Nome:</label>
        <input type="text" name="nome" id="inome">
        <label for="isobrenome">Sobrenome:</label>
        <input type="text" name="sobrenome">id="isobrenome">

Isso é muito importante para que seja feita a ligação/associação entre o texto e o campo de preenchimento, e também para que os mecanismos de busca possam identificar os elementos corretamente, e também o navegador do usuário faça com que o campo funcione corretamente, além disso para telas portateis, se a pessoa cliente em cima da palavra o campo já será acionado para preenchimento dos dados.

Importante!

Sempre devemos utilizar a tag <label> para criar a ligação/associação entre o texto e o campo de preenchimento.
