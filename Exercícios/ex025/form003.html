Formularios com datas e horas.

Primeiro vamos criar um formulário simples.

Como pudemos ver acima, criamos um formulário com o campos média, mês, dia e hora, cada um deles foi um atributo inserido no elemento <input>.

Para o campo de média utilizamos os atributos "min", "max" e "step", e além deles utilizamos o valor number para o atributo type.

O atributo type define o tipo de entrada que será exibida para o usuário e qual o tipo de dado ele pode inserir no campo, e neste caso escolhemos o tipo number. Além dele colocamos o atributo required para tornar o campo obrigatório, o atributo placeholder para fornecer um exemplo de valor esperado, o atributo min para definir o valor mínimo,o atributo max para definir o valor máximo, e o atributo step para definir o intervalo do valor a ser preenchido, como por exemplo de 0,5 em 0,5.

Para o campo de mês utilizamos o valor month para o atributo type, e com ele podemos incluir o mês e o ano desejados para o que está sendo solicitado.

Para o campo dia utilizamos o valor date para o atributo type, e com ele podemos incluir a data desejada para o que está sendo solicitado.

Para o campo hora utilizamos o valor time para o atributo type, e com ele podemos incluir a hora desejada para o que está sendo solicitado.

Existem muitos outros tipos de valores que podemos incluir no atributo type para definir qual o tipo de dado de entrada deve ser solicitado.
