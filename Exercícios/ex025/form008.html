Nesta aula criamos as páginas form008, form009 e form010, e todas elas com a funcionalinalidade do elemento <output>.

Neste momento estamos apenas arranhando a superficie e bem de leve mesmo do javascript com essa função.

Nossos códigos ficaram assim:

        <form action="formulario.php" method="post" autocomplete="on">
            <p>
                <label for="in1">Número 1:</label>
                <input type="number" name="n1" id="in1" min="0" max="50" required oninput="isoma.innerHTML = Number(in1.value) + Number(in2.value)">
            </p>

            <p>
                <label for="in2">Número 2:</label>
                <input type="number" name="n2" id="in2" min="0" max="50" required oninput="isoma.innerHTML = Number(in1.value) + Number(in2.value)">
            </p>

            <p>
                <label for="isoma">Soma:</label>
                <output name="soma" id="isoma">0</output>
            </p>

            <p>
                <input type="submit" value="Enviar">
                <input type="reset" value="Limpar">
            </p>
        </form>

Com esse código podemos ver que o elemento <output> foi utilizado para exibir a soma dos valores selecionados na primeira e na segunga caixa de opções de forma automática.

O código da página form009 ficou assim:

        
        <form action="formulario.php" method="post" autocomplete="on">
            <label for="inum">Número</label>
            <input type="range" name="num" id="inum" min="0" max="10" value="5" oninput="ival.innerHTML = Number(inum.value)">
            <output id="ival">5</output>
            <p>
                <input type="submit" value="Enviar">
                <input type="reset" value="Limpar">
            </p>
        </form>

No código acima o código JavaScript é utilizado para atualizar o valor do elemento <output> com o valor selecionado no controle de faixa (range).
