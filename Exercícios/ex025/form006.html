Color, range e file

Nesta aula vamos ver os últimos tipo de controles de formulários utilizando os controles input type="".

Primeiro vamos criar nosso formulário de exemplo:

Cor, Nível de Satisfação e Foto

No formulário acima, você pode ver que criamos um seletor de cores, um controle de intervalo para o nível de satisfação, e um campo para upload de arquivos.

O primeiro deles foi com o contrato input type="color", que permite ao usuário selecionar uma cor dentro no nosso formulário.

O segundo foi o controle input type="range", que permite ao usuário selecionar um valor dentro de um intervalo especificado num seletor de faixa, arrastando com o mouse ou o dedo no caso de dispositivos móveis.

O terceiro controle foi o input type="file", que permite ao usuário selecionar um arquivo do seu dispositivo para ser enviado junto com o formulário. Ele é comumente usado para upload de fotos, documentos, ou outros tipos de arquivos.

Neste último controle, só será possível o envio do arquivo se estivermos utilizando em nosso código de formulário o método POST.

Não podemos esquecer também que podemos dentro dos controles definir qual é o valor inicial para cada um deles com exceção do input type="file", utilizando o atributo value.
