Formulário de Cadastro

Acabamos de criar um formulário de envio de login e senha, entretanto, mesmo que não coloquemos nenhum dado nos campos, o formulário será enviado ao servidor.

O código que criamos ficou da seguinte forma:

        <form action="formulario.php" method="post">
            <p>
                <label for="isu">Usuário:</label>
                <input type="text" name="usu" id="isu">
            </p>
            <p>
                <label for="isen">Senha:</label>
                <input type="password" name="sen" id="isen">
            </p>
            <p>
                <input type="submit" value="Enviar">
                <input type="reset" value="Limpar">
            </p>
        </form>

Agora vamos aprender mais um atributo importante para que o formulário não seja enviado sem o preenchimento obrigatório de dados.

O atributo required é usado para indicar que um campo de formulário é obrigatório e deve ser preenchido antes de o formulário ser enviado. Se um campo com o atributo required não for preenchido, o navegador exibirá uma mensagem de erro e impedirá o envio do formulário até que o campo seja preenchido corretamente.

O atributo required deve ser inserido no elemento <input> que deseja tornar obrigatório.

O codigo acima ficou da seguinte forma:

        <form action="formulario.php" method="post">
            <p>
                <label for="isu">Usuário:</label>
                <input type="text" name="usu" id="isu" required>
            </p>
            <p>
                <label for="isen">Senha:</label>
                <input type="password" name="sen" id="isen" required>
            </p>
            <p>
                <input type="submit" value="Enviar">
                <input type="reset" value="Limpar">
            </p>
        </form>

Mais atributos para formulários.

Podemos também determinar o tamanho mínimo e máximo de caracteres para os campos do formulário, para isso utilizamos os atributos minlength e maxlength, e da mesma forma o atributo deve ser inserido no elemento <input>.

O código do formulário com os atributos de tamanho mínimo e máximo ficou da seguinte forma:

O código do formulário acima ficou da seguinte forma:

        <form action="formulario.php" method="post">
            <p>
                <label for="isu">Usuário:</label>
                <input type="text" name="usu" id="isu" required minlength="6" maxlength="12">
            </p>
            <p>
                <label for="isen">Senha:</label>
                <input type="password" name="sen" id="isen" required minlength="8" maxlength="15">
            </p>
            <p>
                <input type="submit" value="Enviar">
                <input type="reset" value="Limpar">
            </p>
        </form>

Tamanho dos campos de entrada.

O atributo size é usado para especificar a largura de um campo de entrada em caracteres. Ele determina quantos caracteres podem ser exibidos no campo de entrada ao mesmo tempo, mas não limita a quantidade de caracteres que o usuário pode digitar.

O código do formulário com o atributo size ficou da seguinte forma:

        <form action="formulario.php" method="post">
            <p>
                <label for="isu">Usuário:</label>
                <input type="text" name="usu" id="isu" required minlength="6" maxlength="12" size="12">
            </p>
            <p>
                <label for="isen">Senha:</label>
                <input type="password" name="sen" id="isen" required minlength="8" maxlength="15" size="15">
            </p>
            <p>
                <input type="submit" value="Enviar">
                <input type="reset" value="Limpar">
            </p>
        </form>

Inclusão de dica do que deve ser preenchido

O atributo placeholder é usado para fornecer uma dica ao usuário sobre o que deve ser preenchido no campo de entrada. Ele é exibido dentro do campo de entrada e desaparece quando o usuário começa a digitar.

O código do formulário com o atributo placeholder ficou da seguinte forma:

        <form action="formulario.php" method="post">
            <p>
                <label for="isu">Usuário:</label>
                <input type="text" name="usu" id="isu" required minlength="6" maxlength="12" size="12" placeholder="Digite seu nome de usuário">
            </p>
            <p>
                <label for="isen">Senha:</label>
                <input type="password" name="sen" id="isen" required minlength="8" maxlength="15" size="15" placeholder="Digite sua senha">
            </p>
            <p>
                <input type="submit" value="Enviar">
                <input type="reset" value="Limpar">
            </p>
        </form>

Opções de autocompletar

O atributo autocomplete é usado para controlar se o navegador deve ou não preencher automaticamente os campos de um formulário com base em entradas anteriores do usuário. Ele pode ser definido como "on" para permitir o preenchimento automático ou "off" para desativá-lo.

Além disso podemos colocar o autocomplete dentro do parametro input. Diferente do que acontece quando colocamos apenas na tag form, quando inserimos esse atributo no input, ele tem diversos valores possíveis.

Os valores de autocomplete dentro do atributo input são:

  • on: Permite o preenchimento automático.
  • off: Desativa o preenchimento automático.
  • name: Indica que o campo é para o nome do usuário.
  • email: Indica que o campo é para o endereço de e-mail do usuário.
  • username: Indica que o campo é para o nome de usuário do usuário.
  • current-password: Indica que o campo é para a senha atual do usuário.
  • new-password: Indica que o campo é para a nova senha do usuário.
  • tel: Indica que o campo é para o número de telefone do usuário.
  • address-line1: Indica que o campo é para a primeira linha do endereço do usuário.
  • address-line2: Indica que o campo é para a segunda linha do endereço do usuário.
  • country: Indica que o campo é para o país do usuário.
  • postal-code: Indica que o campo é para o código postal do usuário.
  • street-address: Indica que o campo é para o endereço completo do usuário.
  • tel: Indica que o campo é para o número de telefone do usuário.
  • tel-national: Indica que o campo é para o número de telefone nacional do usuário.

Esses são apenas alguns dos valores disponíveis para o atributo autocomplete dentro do elemento input.

No nosso caso o código ficaria assim:

        <form action="formulario.php" method="post" autocomplete="on">
            <p>
                <label for="isu">Usuário:</label>
                <input type="text" name="usu" id="isu" required minlength="6" maxlength="12" size="12" placeholder="Digite seu nome de usuário" autocomplete="username" autocomplete="username">
            </p>
            <p>
                <label for="isen">Senha:</label>
                <input type="password" name="sen" id="isen" required minlength="8" maxlength="15" size="15" placeholder="Digite sua senha" autocomplete="current-password">
            </p>
            <p>
                <input type="submit" value="Enviar">
                <input type="reset" value="Limpar">
            </p>
        </form>
