Formulários

Nesta aula vamos ver alguns elementos de formulários fora da tag <input>.

Primeiro vamos criar nosso formulário de exemplo:

Formulário de Opções e Caixa de Texto


Seletc, Option e Optgroup:

O primeiro exemplo do nosso formulário foi utilizando o controle <select></select>, com ela é possível criar uma lista de opções a serem selecionadas pelo usuário, e dentro dela cada opção a ser selecionada deve ser colocada dentro de uma tag <option>.

Além disso dentro da tag <select></select> podemos separar as opções da lista que colocaremos dentro do elemento <option> utilizando a tag <optgroup>, nela devemos especificar um rótulo para agrupar as opções relacionadas com um label (atributo não elemento) e com isso conseguimos colocar grupos separados dentro da lista que criamos.

Datalist

O segundo elemento que usamos para este formulário foi a tag <datalist>, que permite criar uma lista de opções pré-definidas para um campo de entrada de texto. Nesta opção podemos ainda usamos um elemento input, entretanto, as opções da nossa lista vão dentro da tag <datalist> e cada opçao dentro de uma option onde especificamos o valor da opção no atributo value.

Textarea

O terceiro campo de nosso formulário foi com o elemento <textarea>, que permite criar um campo de texto multilinha para a entrada de dados. Nela determinamos o número de colunas e linhas do campo que serão viziveis ao usuário, entretanto, pelo menos aqui, não delimitamos o tamanho máximo do texto.

Importante

Na tag <optgroup>, o atributo label define o nome do grupo de opções, que é diferente do elemento label que está associado a um campo de entrada específico, ou seja, o label de <optgroup> é apenas para fins de organização visual, enquanto o label de um campo de entrada é usado para rotular o próprio campo.
