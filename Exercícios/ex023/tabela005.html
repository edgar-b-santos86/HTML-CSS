Nesta aula tivemos a explicação sobre como fazer a formatação de tabelas com as CSSs, e fizemos a configuração para linhas, que é muito fácil de implementar, basta criar uma classe para cada linha e aplicar os estilos desejados.

Porém, o mesmo não se aplica para as colunas, entretanto, temos uma nova tag em HTML5 chamada <colgroup>, e para cada coluna que queremos aplicar os estilos, devemos colocar dentro da tag <colgroup> a tag <col>.

Aplicando o estilo nas linhas de uma tabela

Para aplicar estilos a linhas específicas de uma tabela, dar uma classe à tag <tr> e em seguida definir os estilos no CSS, é algo simples assim como no exemplo abaixo.

        <table>
            <tr class="linha1">
                <th scope="col">Nome</th>
                <th scope="col">Idade</th>
                <th scope="col">Sexo</th>
                <th scope="col">Profissão</th>
            </tr>
            <tr class="linha2">
                <td>Ana</td>
                <td>25</td>
                <td>Feminino</td>
                <td>Engenheira</td>
            </tr>
            <tr class="linha1">
                <td>Bruno</td>
                <td>30</td>
                <td>Masculino</td>
                <td>Professor</td>
            </tr>
            <tr class="linha2">
                <td>Carla</td>
                <td>28</td>
                <td>Feminino</td>
                <td>Advogada</td>
            </tr>
            <tr class="linha1">
                <td>Diego</td>
                <td>35</td>
                <td>Masculino</td>
                <td>Médico</td>
            </tr>

O resultado da aplicação do estilo para as linhas da tabela é o seguinte:

Informações Pessoais
Nome Idade Sexo Profissão
Ana 25 Feminino Engenheira
Bruno 30 Masculino Professor
Carla 28 Feminino Advogada
Diego 35 Masculino Médico

Aplicando o estilo nas colunas de uma tabela

Para aplicar estilos a colunas específicas de uma tabela, utilizamos a tag <colgroup> e a tag <col>. Cada <col> representa uma coluna e pode ter uma classe associada para aplicar estilos.

Vejamos o exemplo abaixo:

        <table>
            <caption>Informações Pessoais</caption>
            <colgroup>
                <col class="coluna1">
                <col class="coluna2">
                <col class="coluna1">
                <col class="coluna2">
            </colgroup>
            <tr>
                <th scope="col">Nome</th>
                <th scope="col">Idade</th>
                <th scope="col">Sexo</th>
                <th scope="col">Profissão</th>
            </tr>
            <tr>
                <td>Ana</td>
                <td>25</td>
                <td>Feminino</td>
                <td>Engenheira</td> 
            </tr>
            <tr>
                <td>Bruno</td>
                <td>30</td>
                <td>Masculino</td>
                <td>Professor</td>
            </tr>
            <tr>
                <td>Carla</td>
                <td>28</td>
                <td>Feminino</td>
                <td>Advogada</td>
            </tr>
            <tr>
                <td>Diego</td>
                <td>35</td>
                <td>Masculino</td>
                <td>Médico</td>
            </tr>

O resultado da aplicação do estilo para as colunas da tabela é o seguinte:

Informações Pessoais
Nome Idade Sexo Profissão
Ana 25 Feminino Engenheira
Bruno 30 Masculino Professor
Carla 28 Feminino Advogada
Diego 35 Masculino Médico

Também podemos utilizar o parametro span para especificar quantas colunas que deve ser aplicado o estilo.

Neste caso aplicaremos o estilo a duas colunas conforme o exemplo abaixo:

        <table>
            <caption>Informações Pessoais</caption>
            <colgroup>
                <col class="coluna1" span="2">
                <col class="coluna2" span="2">
            </colgroup>
            <tr>
                <th scope="col">Nome</th>
                <th scope="col">Idade</th>
                <th scope="col">Sexo</th>
                <th scope="col">Profissão</th>
            </tr>
            <tr>
                <td>Ana</td>
                <td>25</td>
                <td>Feminino</td>
                <td>Engenheira</td> 
            </tr>
            <tr>
                <td>Bruno</td>
                <td>30</td>
                <td>Masculino</td>
                <td>Professor</td>
            </tr>
            <tr>
                <td>Carla</td>
                <td>28</td>
                <td>Feminino</td>
                <td>Advogada</td>
            </tr>
            <tr>
                <td>Diego</td>
                <td>35</td>
                <td>Masculino</td>
                <td>Médico</td>
            </tr>
    </table>

O resultado da aplicação do estilo para as colunas da tabela utilizando o parametro span é o seguinte:

Informações Pessoais
Nome Idade Sexo Profissão
