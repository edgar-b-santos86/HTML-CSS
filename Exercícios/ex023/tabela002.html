Anatomia de Tabelas Grandes

O HTML5 trouxe várias tags semânticas para desenvolvimento de sites como as tags <header>, <nav>, <main>, <section>, <article>, <aside> e <footer>.

Acontece que para tabelas com grandes quantidades de dados, o HTML5 também trouxe tags semânticas específicas para melhorar a estrutura e a acessibilidade dessas tabelas, e isso é uma recomendação do W3C.

A Anatormia de tabelas grandes é diferente das tabelas pequenas. Nela temos a tag <table>, dentro dela temos a tag <thead> para o cabeçalho e a tag <tbody> para o corpo da tabela e <tfoot> para o pé, e dentro de cada uma delas podemos ter o <tr>, o <th> e o <td>.

Além dessas tags temos também o <caption> que nada mais é que a legenda da tabela.

Escopo de Títulos em Tabelas

O escopo de títulos em tabelas define a relação entre os cabeçalhos e as células de dados, melhorando a acessibilidade e a compreensão da estrutura da tabela, além de tornar mais relevante o conteúdo para os serviços de busca.

Pra isso usamos o atributo scope nas tags <th>, além disso esse atributo pode ser definido com os valores row que relaciona o th com a linha, col que relaciona o th com a coluna.

Temos também os valores rowgroup e colgroup que relacionam os cabeçalhos com grupos de linhas ou colunas.

Efeito Zebrado

Para criarmos o efeito zebrado, podemos utilizar o seletor de pseudo-classe :nth-child() no CSS.

Para este seletor poodemos colocar entre os parentezes :nth-child(even) para estilizar as linhas pares ou :nth-child(odd) para estilizar as linhas ímpares.

Ainda podemos também utilizar o atributo nth-child(2n) para criar um padrão mais complexo de efeito zebrado. E podemos estabelecer até que a regra seja aplicada para cada 3 ou mais linhas apenas mudando de 2 para qualquer número antes do n.

Fixando o Cabeçalho da Tabela

Para fazermos esse efeito o primeiro passo é darmos a nossa tabela a posição relativa, conforme está no exemplo da CSS abaixo:

            
                table {
                    position: relative;
                }

Depois devemos fixar o cabeçalho colocando a declaração em CSS dando o exato local que queremos fazer isso, e definimos as propriedades position e top, e também devemos colocar o mesmo background-color que definimos para o cabeçalho da tabela assim como no exemplo:

            
                thead > tr > th {
                    position: sticky;
                    top: -1px;
                    background-color: gray;
                }

Para a propriedade position: inserimos o valor sticky a ser aplicada, para a propriedade top definimos a posição vertical, e inserimos o valor -1px, isso faz com que o cabeçalho fique bem colado no topo do navegador quando vai tendo a rolagem vertical, e além disso como informamos antes, utilizamos o mesmo background-color utilizado no cabeçalho.
