Hierarquia de Tabelas (Simples)

A Hierarquia de tabelas simples é designada da seginte forma:

  • <table></table> - Define a tabela
  • <tr></tr> - Define uma linha na tabela (table row), que vai dentro do table.
  • <th></th> - Define um cabeçalho na tabela (table header)
  • <td></td> - Define uma célula na tabela (table data)

Vamos começar trabalhando com os dados de tabela..

A1 B1 C1
A2 B2 C2
A3 B3 C3
A4 B4 C4

Para criar o resultado acima fizemos o seguinte código:

            
                <table>
                    <tr>
                        <td>A1</td>
                        <td>B1</td>
                        <td>C1</td>
                    </tr>
                    <tr class="linha">
                        <td>A2</td>
                        <td>B2</td>
                        <td>C2</td>
                    </tr>
                    <tr>
                        <td>A3</td>
                        <td class="dado">B3</td>
                        <td>C3</td>
                    </tr>
                    <tr>
                        <td>A4</td>
                        <td>B4</td>
                        <td>C4</td>
                    </tr>
                </table>

Já o estilo utilizado foi esse:

            
                table {
                    width: 300px;
                    border-collapse: collapse;
                    border: 3px solid black;
                }

                tr.linha {
                    background-color: aqua;
                }

                td {
                    border: 1px solid black;
                    padding: 5px
                }

                td.dado {
                    background-color: lightslategray;
                }

Dentro do HTML5 e CSS3 tem um novo recurso que é a propriedade de estilo table-collapse, que por padrão tem o valor separate, o que deixa as bordas das linhas separadas mas, para que possamos deixar a tabela com uma configuração de estilo mais "convencional", usamos o valor collapse que vai fazer com que os dados fiquem juntos, pois neste caso o que fizemos foi criar as bordas nos dados, e fizemos com que as bordas ficassem juntas.

O W3C diz que para o HTML 5 não é necessário o fechamento das tags tr, th, td, entretanto, temos que tomar muito cuidado para não miturarmos as informações nas celulas, linhas ou cabeçalhos que inserimos em nossas tabelas.

Apenas de não precisar fechar as tags, o indicado é fechar as tags para que os erros sejam minimizados.

ATENÇÃO!

Se não colocarmos os elementos na hierarquia correta, os dados inseridos podem aparecer ou antes ou depois de sua tabela, ou simplesmente linhas ou células podem não aparecer.

Alinhando o conteúdo em tabelas.

Vamos refazer nossa Tabela, porém, vamos pegar nosso modelo apenas como tabela sem alterações.

O que vamos fazer agora é o alinhamento horizontal e vertical.

O alinhamento horizontal do <td> por padrão é a esquerda, e para configurarmos ele de forma diferente utilização a propriedade text-aling dentro das CSS e incluím os os valores left, center ou right, para assim alinharmos a esquerda, centro ou à direita da celula.

Já para o alinhamento vertical, utilizamos a propriedade vertical-aling, e dentro desta utilizamos os valores top, middle ou bottom, para alinhamento dentro da célula em cima, no meio ou embaixo

A1 B1 C1
A2 B2 C2
A3 B3 C3
A4 B4 C4

No exemplo acima e na tabela anterior, a declaração para o <td> ficou assim.

        
            td {
                border: 1px solid black;
                padding: 5px;
                text-align: center;
                vertical-align: middle;
            }
