Flex-Item ou itens flexiveis.

Nesta aula vamos falar sobre outros dois valores que temos além do auto e também dos tamanhos fixos que podemos dar aos itens dentro do contêiner, flex-grow e flex-shrink.

flex-grow define o quanto o item pode crescer em relação ao conteúdo disponível no contêiner.

flex-shrink define o quanto o item pode encolher em relação ao conteúdo disponível no contêiner.

Por padrão, o flex-shrink tem valor 1, ou seja, os itens podem encolher se necessário. Se o valor for 0, isso determina que os itens não podem encolher.

Já no flex-grow o valor padrão é 0, ou seja, isso define que os itens não podem crescer. Se o valor for 1, ai os itens podem se necessário crescer.

Vamos agora fazer um exercício de exemplo.

Se quisermos que os itens dentro de um contêiner cresçam e diminuam ao máximo, neste caso, sempre vamos dar os valores 1 tanto para o flex-grow quanto para o flex-shrink.

Exemplo

A
Ex B
Exem C

Nosso código HTML está desenvolvido da seguinte forma:

        <div class="conteiner">
            <div class="item" id="ia">A</div>
            <div class="item" id="ib">Ex B</div>
            <div class="item" id="ic">Exem C</div>
        </div>

Na CSS os comando ficaram assim:

        div.item {
            background-color: lightblue;
            border: 1px solid black;
            text-align: center;
            padding: 10px;
            flex-basis: 250px;
            flex-shrink: 1;
            flex-grow: 1;
        }

No nosso exemplo, colocamos um tamanho fixo no flex-basis de 250px, e os valores 1 para flex-shrink e flex-grow. Com isso os itens vão crescer e encolher conforme necessário.

O flex-grow e flex-shrink podem ter valores diferente de 0 e 1, e podemos definir valores para cada um dos itens. A depender o valor, se por exemplo temos três itens e colocaremos os valores de flex-grow com 0, 1 e 2, por exemplo. Neste caso o primeiro elemento não vai crescer, o segundo elemento vai crescer e o terceiro elemento vai crescer o dobro em relação ao segundo elemento proporcionalmente.

A mesma lógica se aplica ao flex-shrink, onde podemos definir valores diferentes para controlar o quanto cada item pode encolher. Digamos que temos três e o primeiro item terá o valor 1, o segundo terá o valor 0, e o terceiro terá o valor 2. O primeiro vai encolher, o segundo não vai encolher e o terceiro vai encolher o dobro com relação ao primeiro.

Ex B
Exem C

Nosso código HTML está desenvolvido da seguinte forma:

        <div class="conteiner">
            <div class="item1" id="ia1">A</div>
            <div class="item1" id="ib1">Ex B</div>
            <div class="item1" id="ic1">Exem C</div>
        </div>

A CSS os comando ficaram assim:

        div.item1 {
            background-color: lightblue;
            border: 1px solid black;
            text-align: center;
            padding: 10px;
            flex-basis: 250px;
            flex-shrink: 1;
            flex-grow: 1;
        }        

        div#ia1 {
            flex-shrink: 3;
            flex-grow: 1;
        }

        div#ib1 {
            flex-shrink: 0;
            flex-grow: 2;
        }

        div#ic1 {
            flex-shrink: 1;
            flex-grow: 0;
        }
