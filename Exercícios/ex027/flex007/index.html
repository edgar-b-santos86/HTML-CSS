Flex-Item ou itens flexiveis.

Nesta aula vamos começar a ver as propriedades que se aplicam ao itens que estão dentro do contêiner flexível.

Quando criamos um contêiner flexbox, apenas o contêiner, a caixa pai é flexível, os itens não são flexíveis, entretanto, podemos fazer com que um item dentro do contêiner também se tone outro contêiner flexível, mas não veremos isso nesse momento.

Primeiro vamos ver duas propriedades para cotrolar os itens filhos, o order e o align-self.

Começando, todos os itens tem como valor padrão 0 para a propriedade order, porém, podemos alterar a ordem dos itens atribuindo valores nessa propriedade e podemos usar tanto números negativos quanto positivos.

No nosso exemplo o código HTML está editado na ordem correta, conforme abaixo:

        <div class="conteiner">
            <div class="item" id="ia">Exemplo de caixa A</div>
            <div class="item" id="ib">Exemplo de caixa B</div>
            <div class="item" id="ic">Exemplo de caixa C</div>
            <div class="item" id="id">Exemplo de caixa D</div>
        </div>

Mas quem determinou a ordem dos itens foi a propriedade order na CSS, e a ordem definida foi essa:

        div#ia {
                order: 3;
            }
            div#ib {
                order: 4;
            }
        
            div#ic {
                order: 0;
            }
        
            div#id {
                order: -1;
            }
