Centralização de itens em flex box

Nesta aula veremos como centralizar os itens dentro do bloco pai, ou seja, do contêiner.

Para isso, basta utilizar as propridades justify-content e align-items, e utilizamos o valor center para ambos.

Exemplo:

Exemplo de caixa A

Com isso, nosso exemplo o nosso CSS ficou da seguinte forma:

        div.conteiner {
            background-color: gray;
            height: 300px;
            display: flex;
            flex-flow: row nowrap;
            justify-content: center;
            align-items: center;
        }
