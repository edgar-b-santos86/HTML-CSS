Empacotamento/Encapsulamento

Nesta Aula veremos mais sobre a declaração flax-wrap.

A declaração flex-wrap: é o empacotamento/encapsulamento da nossa caixa/conteiner pai. Essa declaração configura a "quebra", por assim dizer do conteúdo que está dentro da caixa principal, e neta nós temos três valores possíveis para utilização:

  1. flex-wrap:nowrap; - Esse valor na declaração faz com que os blocos/caixas não tenham quebra para a linha de baixo ou coluna ao lado, fazendo com que esses blocos se comprimam, incolher, sempre dependendo do conteúdo que foi inserido no bloco/caixa. Esse valor inclusive é o padrão caso não façamos a inserção da declaração.
  2. flex-wrap:wrap; - Esse valor determina que o último elemento quebre ele no sentido do eixo transversal, ou seja para o sentido do cross-axis, ou seja, o último elemento vai para linha de baixo no caso de estarmos usando a declaração flex-direction: row; ou para a coluna ao lado se estivermos usando a declaração flex-direction: column;
  3. flex-wrap:wrap-reverse; - Esse valor determina que os blocos ou caixas do último no espaço do conteiner/bloco pai sejam direcionados no sintido oposto do cross-axis
    .

Shorthand flex-flow

A propriedade flex-flow é a junção das declaraçãos flex-direction e flex-wrap, que foi o que usamos nas CSS deste exercício e ficou assim:

        <style>
            * {
                font-family: Arial, Helvetica, sans-serif;
            }
            div.conteiner {
                background-color: lightgray;
        
                display: flex;
                flex-flow: row wrap;
            }
            div.item {
                background-color: lightblue;
                border: 1px solid black;
                text-align: center;
                padding: 10px;
            }
        </style>

Declaração flex

A declaração flex: auto; funciona apenas para os conteineres/blocos filhos, e essa declaração vai fazer com que o conteúdo dos blocos filhos sejam ocupem todo o espaço de disponível do bloco pai.
