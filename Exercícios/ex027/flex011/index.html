Flex-Item ou itens flexiveis.

Nesta aula vamos ver como utilizar a shorhand flex. Através dela podemos definir os valores de flex-grow, flex-shrink e flex-basis em uma única declaração, e a ordem é exatamente essa para a a shorthand flex:

  1. flex-grow; - define o quanto o item pode crescer em relação ao conteúdo disponível no contêiner;
  2. flex-shrink; - define o quanto o item pode encolher em relação ao conteúdo disponível no contêiner;
  3. flex-basis; - define o tamanho inicial do item antes de ele crescer ou encolher, ou seja, o tamanho base do item;

A shorthand fica assim: flex: flex-grow flex-shrink flex-basis;

Ex B

Nosso código HTML está desenvolvido da seguinte forma:

        <div class="conteiner">
            <div class="item1" id="ia1">A</div>
            <div class="item1" id="ib1">Ex B</div>
            <div class="item1" id="ic1">Exem C</div>
        </div>

A CSS os comando ficaram assim:

        div.item1 {
            background-color: lightblue;
            border: 1px solid black;
            text-align: center;
            padding: 10px;
            flex-basis: 250px;
            flex-shrink: 1;
            flex-grow: 1;
        }        

        div#ia1 {
            flex: 3 1 250px;
        }

        div#ib1 {
            flex: 0 2 250px;
        }

        div#ic1 {
            flex: 1 0 250px;
        }

A recomendação da W3C é utilizar a shorthand flex para definir os valores de flex-grow, flex-shrink e flex-basis em uma única declaração, porém, existem mais simplificações da propriedade flex que podem ser utilizadas, e são elas:

  • flex: none; - esse valor é equivalente a flex: 0 0 auto;, ou seja, os itens não crescem, não encolhem e o tamanho base é definido pelo conteúdo do item;
  • flex: auto; - esse valor é equivalente a flex: 1 1 auto;, ou seja, os itens podem crescer e encolher se necessário, e o tamanho base é definido pelo conteúdo do item;
  • flex: initial; - esse valor é equivalente a flex: 0 1 auto;, ou seja, os itens não crescem, podem encolher se necessário, e o tamanho base é definido pelo conteúdo do item;

Podemos ainda definir apenas o valor de flex-grow onde o valor de flex-shrink e flex-basis são assumidos como 1 e 0, respectivamente.
