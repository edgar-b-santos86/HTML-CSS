Flex-Item ou itens flexiveis.

Agora vamos ver como funciona o align-self, essa propriedade permite controlar o posicionamento dos itens no eixo transversal, ou o cross-axis.

Existem 5 valores possíveis para a propriedade align-self e são:

  • stretch; - esse valor faz com que o item se estique para preencher todo o espaço disponível no eixo transversal, que é o padrão caso não seja especificado o valor;
  • flex-start; - esse valor faz com que o item tenha seu alinhamento no início do eixo transversal, e se houver alguma sobra de espaço disponível, ele será "colocado" no final do eixo transversal;
  • flex-end; - esse valor faz com que o último item do conteúdo seja alinhado no final do eixo transversal, e como consequência o espaço em branco do bloco (se houver), é colocado no início do eixo transversal;
  • center; - esse valor faz com que o item dentro do bloco seja alinhado no centro do eixo transversal;
  • auto; - esse valor faz com que o item herde o valor da propriedade align-items; do contêiner pai, ou seja, do bloco onde ele está inserido;

Nosso código HTML está desenvolvido da seguinte forma:

        <div class="conteiner">
            <div class="item" id="ia">Exemplo A</div>
            <div class="item" id="ib">Exemplo B</div>
            <div class="item" id="ic">Exemplo C</div>
            <div class="item" id="id">Exemplo D</div>        
            <div class="item" id="if">Exemplo F</div>
        </div>

O que determinou o posicionamento dos itens neste exemplo foi a propriedade align-self aplicada a cada um deles, conforme configurado na CSS:

        div#ia {
                align-self: flex-start;
            }
            div#ib {
                align-self: flex-end;
            }
        
            div#ic {
                align-self: center;
            }
        
            div#id {
                align-self: flex-stretch;
            }
        
            div#if {
                align-self: auto;
            }
