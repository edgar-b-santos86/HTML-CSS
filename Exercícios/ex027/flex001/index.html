Trabalhando com Flex Box

Neste capitulo falaremos sobre CSS Flexible Boxes Module Level 1 ou Flex Box.

Flex Box é um módulo de CSS que trata de caixas flexiveis, ou seja, trata da responsividade que antes ficavam limitadas apenas as Medias Queries.

No CSS 3 surgiram varias coisas que ajudaram em muito na responsividade dos sites. o Flex Box foi apenas um dos módulos que sugiram, além dele foi implementada também o CSS Grid Layout Module Level 1/2, mais conhecido como Grid Layout.

Devemos ter em mente o surgimento do CSS 3 com os módulos de Flex Box e Grid Layout, não tornam as demais técnincas de responsividade, e métodos, alinhamento, posicionamento e de organização de conteúdo do CSS 2.1 erradas ou inutilizáveis, bem pelo contrário, ainda é super viável válido a utilização para que todas sejam integradas no desenvolvimento do nosso site.

Algumas da técnicas do CSS dois são:

  • Block Layout;
  • Inline Layout;
  • Table Layout;
  • Positioned Layout;

Sempre que pensarmos em FlexBox, devemos pensar, qual é o formato da água?

Depende! Isso mesmo, depende de onde eu vou colocar a água. Onde eu a coloco determina o seu formato.

O flex box é exatamente isso, dependendo do tamanho do contêiner onde o conteúdo do site é mostrado, o conteúdo será adaptado e isso vai sofrer as mudanças de acordo com o tamanho que o conêiner tiver.

Como exemplo se criarmos uma div e dentro dela colocarmos outras divs, para que o conteúdo e adpte devemos, a princípio utilizar para a div "pai" o parâmetro display: flex;, e para a divs "filhos", devemos utilizar os parâmetros flex:auto; com isso dependendo do tamanho que a div externa tomar automáticamente as internas vão se adaptar e tomar forma e tamanhos automáticos, entretanto, podemos determinar qual vai ser o comprotamento de adptação do conteúdo.

Importante!

O elemento "pai" sempre será o contêiner ou flex-container do nosso código, ou seja, seja a caixa em que todas as outras e o conteúdo do site será colocado e apenas ele poderá ter a propriedade flex; os elementos "filho", os itens ou flex-items não podem ter essa propriedade.

Primeiro criamos as divs e como podem ver temos a div "pai" com a class="conteiner" e as divs "filho" estão com a class="item"

        <style>
            div.conteiner {
                background-color: lightgray;
                display: flex;
            }
            div.item {
                background-color: lightblue;
                border: 1px solid black;
                flex: auto;
            }
        </style>

Depois criamos a CSS e inticamos os parâmentros diplay: flex; para oconteiner ou div pai e com isso já temos flexibilidade da div principal, e após atribuímos o parâmetro flex: auto; para que automáticamento os itens ou divs filho tivessem seus tamanhamos adaptados também automaticamente.
