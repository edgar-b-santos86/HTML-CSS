Flex-Item ou itens flexiveis.

Vamos falar agora sobre a propriedade flex-basis, essa propriedade também se aplica aos itens dentro de um contêiner flexível.

Por padrão, a propriedade flex-basis tem o valor auto, ou seja, a largura de cada item vai depender do conteúdo que está nele, e neste caso mesmo que o contêiner tenha espaço sobrando, os itens não vão ocupar o espaço disponível.

Caso coloquemos um tamanho específico para essa propriedade, os itens vão respeitar esse tamanho, entretanto, vai depender também do tamanho do contêiner ou seja ele vai diminuir se necessário e todos os itens vão ter o mesmo tamanho.

Vamos agora fazer um exercício de exemplo.

Exemplo

A
Ex B
Exem C
Ex D
Exemplo F

Nosso código HTML está desenvolvido da seguinte forma:

        <div class="conteiner">
            <div class="item" id="ia">A</div>
            <div class="item" id="ib">Ex B</div>
            <div class="item" id="ic">Exem C</div>
            <div class="item" id="id">Ex D</div>        
            <div class="item" id="if">Exemplo F</div>
        </div>

Na CSS os comando ficaram assim:

        div.item {
            background-color: lightblue;
            border: 1px solid black;
            text-align: center;
            padding: 10px;
            flex-basis: auto;
        }

A propriedade flex-basis no nossso exemplo está como auto e definiu aqui que cada item deveria ter a largura de acordo com o tamanho do conteúdo que estava dentro dele, automaticamente.
