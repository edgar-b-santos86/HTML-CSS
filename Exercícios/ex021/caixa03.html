Teste de Borda Personalizada

Nesta aula verificamos como criar bordas personalizadas em elementos HTML, utilizando as CSS.

A primeira coisa que foi ensinada foi como criar a imagem que vai servir como borda.

Abrimos o GIMP e criamos uma imagem de borda personalizada.

Vamos agora aplicar essa imagem criando uma borda em um elemento HTML, para isso vamos primeiro criar um seletor em CSS para o nosso H1.

Como podemos ver já criamos nossa borda personalizada no H1 utilizando as seguintes propriedades via CSS:

  • border: 9px solid black
  • border-image-source: url('borda.png')
  • border-image-slice: 27
  • border-image-repeat: repeat

Sempre que vamos fazer uma borda personalizada, precisamos primeiro incluir a propriedade border pois ela é que fixa a borda no elemento desejado.

Em seguida, utilizamos a propriedade border-image-source para especificar a imagem que será usada como borda.

A proxima propriedade que utilizamos é border-image-slice, que define como a imagem de borda será cortada/fatiada.

Por fim, utilizamos a propriedade border-image-repeat para definir como a imagem de borda será repetida ao redor do elemento. No nosso caso, utilizamos o valor "repeat" para que a imagem seja repetida tanto horizontalmente quanto verticalmente.

Com essas propriedades, conseguimos criar uma borda personalizada para o nosso elemento H1 utilizando a imagem que criamos no GIMP.
